## 内容
task 021 の実装中に、`SECTION_KEYS`（`原因` `評価` `結論` `結語` `再発防止` `提言`）を見出し全体に対して探すと
`9502_chubu_report_full.txt` の

```
第4 中部電力による地震動評価及び基準地震動の策定に関して本委員会が認定した事実
```

が `評価`（地震動**評価**）に当たってしまう。05-state構築 4.5 は「9502 で拾えるのは `第6 原因分析`・`第7 再発防止策の提言`・`第8 結語` の3章」と書いており、実装と食い違う。
`max_excerpts` が 4 なので4章とも抜粋に入り、T05-13 が落ちる。第4章は「認定した事実」の章で、要件 F2-4 が求めている「原因・評価・結論・再発防止」の章ではない。

## 完了条件
- キーワードの当て方を決めて 4.5 に書く
- `extract_sections` が 9502 で3章だけを返し、T05-13 が通る

## メモ
- 2026-09-20：**キーワードは章題の末尾側（最後の12文字）に現れるものだけを採る**ことにした。章の主題は章題の終わりに来る（「…原因分析」「…再発防止策の提言」「…結語」）のに対し、誤爆する語は長い修飾の途中に現れる（「…地震動評価及び…認定した事実」）。文字数の上限で切る案（見出し20字以内）も考えたが、長い章題の正しい章を落とすので採らなかった
