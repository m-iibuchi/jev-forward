## 内容
TDnet の新着一覧を1分周期で機械取得する方法を確定する。候補：
1. 適時開示情報閲覧サービスの公開ページ（HTML）を取得して解析する。利用条件（robots、規約、アクセス頻度の制限）を確認する
2. 有料の開示データ API（TDnet データ配信サービス等）。月額と契約条件
3. 代替：J-Quants の開示情報（あれば）、各社 IR ページ（現実的でない）

`tests/fixtures/tdnet_list_2026-09-17.tsv` は公開ページの表をコピーしたもの。列：時刻、コード、会社名、表題、XBRL、上場取引所、更新履歴。公開ページ解析の場合はこの列構成が取れることを確認する。

## 完了条件
- 取得方法を1つ決め、利用条件の根拠（URL、規約の該当箇所）をこのファイルに書く
- 1分周期・並列なしで問題ないことを確認する
- PDF と XBRL の URL の形式を記録する
- 決まったら ADR を作る（fetch 層の差し替え可能性は維持）
