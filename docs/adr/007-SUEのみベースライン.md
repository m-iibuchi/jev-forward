# 007: SUEのみをベースラインに含める

- Status: Accepted
- Date: 2026-09-19
- Related: 要件3章「ベースライン」、2章「外部の証拠」

## Context
決算短信の見通しをLLMでセンチメント化してSUEと掛け合わせる研究（JSAI FIN-035, 2025）が既にあり、PEAD自体は日本市場で有意（大阪大学 DP 2125）。本システムがランダムとTOPIXに勝っても、それが「Jevが数値以上の情報を足している」証拠にはならない。数値だけで同じ成績が出るなら Jev は不要。

## Decision
ベースラインに「SUEのみ」を加える。Jevを使わず、営業利益の修正率（業績予想修正）または実績と前回予想の差（決算短信）の上位から、主検証と同じ件数・同じ除外・同じ流動性条件で選ぶ。関門1は3ベースラインすべてに有意に勝つことを要求する。

## Alternatives
- ランダムとTOPIXのみ：Jevの付加価値を測れない
- 他のLLMとの比較：モデル間比較は目的ではない。段階2以降のタスク

## Consequences
- SUEの計算材料（前回予想・実績）を XBRL から取る必要がある（要件F2-3）。取得できない件は SUE ベースラインの母集団から外し、その件数を記録する
- 「修正率」の定義（営業利益ベース、分母は前回予想の絶対値、赤字転換の扱い）を事前宣言に固定する
