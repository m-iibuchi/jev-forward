# 008: 暗号資産での練習を省略

- Status: Accepted
- Date: 2026-09-19
- Related: 要件9章 段階1、検証ログ

## Context
初期案では、24時間動く暗号資産市場でロガー・判定・採点の一連を練習してから日本株に移る予定だった。Playgroundで52回・32件の検証を行い、方向判定・束ね・主語固定文・入力上限・再現性を実データで確認できた。

## Decision
暗号資産での練習は省略し、段階1から日本株の TDnet で始める。

## Alternatives
- 予定通り練習する：学習目的は Playground で達しており、暗号資産の取得層・採点層を作る工数が無駄になる

## Consequences
- 取得層・採点層の差し替え可能性は設計原則として残す（要件4章）が、実装は日本株のみ
