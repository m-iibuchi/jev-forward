# 011: 主検証の母集団は引け後開示のみ

- Status: Accepted
- Date: 2026-09-20
- Related: 要件3章「対象開示」「1件の定義」、`docs/事前宣言.md`、ADR 005

## Context
採点の起点は翌営業日の始値（ADR 005）。場中（9:00〜15:00）の開示は当日中に株価が反応するため、翌朝寄りでエントリーすると初日の反応を丸ごと逃す。場中開示を主検証に混ぜると、母集団は増えるが平均超過リターンは薄まり、「引け後開示のPEAD」という仮説の検証にならない。Playgroundの答え合わせでも場中開示（ハマイ、中部電力）は当日中に動いていた。

## Decision
- 主検証の母集団は **公表時刻が 15:00:00 JST 以降、翌営業日 8:59:59 JST 以前** の開示に限る（東証の立会時間外）。休日・夜間の開示は次の営業日の寄りでエントリー
- 場中開示は判定・凍結・採点をすべて行うが、`bundles.session` = `intraday` として主検証から外し、探索として集計する
- `bundles.session` は `after_close` / `intraday` / `pre_open`（8:00〜8:59 は after_close と同じ扱いだが区別のため別値）で記録

## Alternatives
- 場中も含めて翌朝寄りで統一：仮説と合わない件で成績を薄める
- 場中開示は当日引けでエントリーする別枝：主検証が2本になる。事前宣言は1本に絞る原則に反する。探索として後で検討

## Consequences
- 立会時間の境界は `config/settings.yaml` の `market.session_close` `market.session_open` から読む（昼休みは考慮しない）
- 事前宣言（事前宣言.md）に明記
- ダイジェスト（ADR 010）は after_close / pre_open のみを候補にする
