# 001: VPS主・NAS副の構成

- Status: Accepted
- Date: 2026-09-19
- Related: 要件4章、基本設計1章・6章

## Context
当初は自宅NAS（DS220+）で常駐させる案だったが、2026-09-19に自宅回線が断となり、取得・判定の欠損が相場と無関係に発生し得ることが明らかになった。凍結ログの欠損は「相場と無関係な欠損は許容、高負荷時に落ちる欠損は許容しない」の原則に照らしても、回線起因の欠損は避けたい。

## Decision
取得・束ね・判定・凍結ログ・監視・通知は VPS（1vCPU・1GB・東京）で常時稼働させる。NAS は VPS の SQLite と原本PDFの日次バックアップ先とする。採点・分析・レポートはローカルPCで非同期に行う。

## Alternatives
- NAS主：回線・電源が自宅依存。却下
- クラウドマネージドDB：コストと複雑さが個人用途に過剰。却下

## Consequences
- VPS は外向き通信のみ。秘密は環境変数
- NAS へは `sqlite3 .backup` のスナップショットを rsync（NAS→VPS の pull でもよい）
- VPS のディスクは有限なので原本PDFの保持期限が必要（ADR 018）
