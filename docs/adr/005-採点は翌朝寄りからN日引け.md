# 005: 採点は翌営業日始値→N営業日後終値

- Status: Accepted
- Date: 2026-09-19
- Related: 要件3章「評価幅」、2章「答え合わせ」、基本設計3.8

## Context
方向が正解でも利益にならない例があった。銚子丸（up 100%）は翌日始値 +8.8% だが寄り→引けは △3.9%。ほぼ日は寄り→引け +6.2%。ニュースの価値の大半は寄り付きギャップで消える。「前日終値→翌日終値」で採点すると、取れないギャップを利益に数える。

## Decision
すべての評価幅の起点は翌営業日の始値（寄り成行の約定想定）とする。終点は N 営業日後の終値。主検証は N=20 の1つのみ。指標は対TOPIX超過リターン、コスト控除後。特別買い気配で寄らない場合は約定なし（`filled=0`）。

## Alternatives
- 前日終値起点：幻の利益。却下
- 場中に付いた最初の値：分足が必要。記録のみに留める（探索）

## Consequences
- 採点には翌営業日の日足が必要。J-Quants Light は前営業日までなので採点は1営業日遅れ
- 「寄らず」の判定には特別気配の識別が必要。初版は「始値が前日終値比で制限値幅いっぱい」を代理指標とし、精緻化はタスク化
