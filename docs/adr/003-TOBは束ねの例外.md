# 003: TOB・MBO・株式交換は束ねの例外

- Status: Accepted
- Date: 2026-09-19
- Related: 要件F1-3、基本設計3.2、検証ログ #11b, 26a/26b

## Context
同一銘柄・同一時刻の開示を束ねると同時開示の二重計上が消える（ほぼ日 #4→#7）。しかしTOB対象銘柄で意見表明と無配・特別損失を束ねると判定が割れた（レオパレス 26a: up 49 / down 38、Confidence 23%）。意見表明のみなら up 85%（26b）。TOB対象銘柄の株価は買付価格でほぼ決まるため、付随の悪材料は株価に効かないが、Jevは字面で悪材料に引かれる。

## Decision
表題に「公開買付」「ＭＢＯ」「MBO」「株式交換」を含む開示があれば、その開示を単独 bundle（`bundle_role='tob_primary'`）にする。同時刻の他の開示は `bundle_role='tob_attached'` の別 bundle とし、判定はするが主検証から除外する。

## Alternatives
- TOB付随を判定しない：欠損の相関分析ができなくなる。判定はして除外する
- 束ねたまま問いにTOBの扱いを足す：v2 の direction criteria に「買付価格と直前株価の比較」を足したが、束ねの悪材料の影響までは消せない

## Consequences
- TOB検知は表題パターン（`config/filters.v1.yaml`）に依存。パターンは版管理
- 主検証の抽出条件は `bundle_role='normal'`
