# 020: 問い版の凍結は CLI freeze-questions で行い、JSONファイルは不変

- Status: Accepted
- Date: 2026-09-20
- Related: CLAUDE.md ルール2、要件6章、基本設計4章 `question_versions`、`config/questions.v2.json` の `_frozen_at`

## Context
`questions.v2.json` は `_frozen_at: null` を持ち、「段階2開始時に設定し以後変更しない」としていた。しかし JSON ファイル自体を書き換えると「既存の版ファイルは絶対に変更しない」（CLAUDE.md ルール2）と矛盾する。また `question_versions.frozen_at` を誰がいつ INSERT するかが未定だった。

## Decision
- 版ファイル `config/questions.vN.json` は作成後に変更しない。`_frozen_at` は `null` のまま残す（互換のためキーは残すが使わない）
- 凍結は CLI `jevfwd freeze-questions --version v2` で行う。JSON を読み、その内容と SHA-256、実行時刻を `question_versions` に INSERT する。同じ版の再実行は既存行と SHA-256 が一致することを確認して何もしない（不一致なら異常終了）
- judge は `question_versions` に凍結済みの版だけを使える。未凍結の版で判定しようとしたらエラー
- 2026-09-20 時点の SHA-256：
  - `config/questions.v1.json` = `14a8baac5898235be756d1c4265fc39541adf13108d9bbc04a445cabf65bd2e7`
  - `config/questions.v2.json` = `3f7b661012e0ab94c22f3012bb76a72cc2a03cd086e26b5208fc5b6455f6bcb0`
- テストで上記ハッシュを固定値として検証し、版ファイルの変更を検知する

## Alternatives
- JSON に `_frozen_at` を書く：ファイル不変の原則と衝突
- git のコミットハッシュで版を表す：DB 単体で版を辿れなくなる

## Consequences
- `state_versions` も同じ方式（`freeze-state --version v2` で `docs/contracts/state.v2.schema.json` を登録）
- 文言を変えたいときは v3 ファイルを新規作成 → 人の承認 → `freeze-questions --version v3` → 件数リセット
