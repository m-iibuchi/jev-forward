# 004: 重複排除はPDFのSHA-256

- Status: Accepted
- Date: 2026-09-19
- Related: 要件F1-3、基本設計3.1・4章、検証ログ #30a

## Context
リベルタ（4935）は同日に同一表題「借入に関するお知らせ」を2件出したが、別の銀行との別契約だった。（公表時刻, コード, 表題）で重複判定すると片方を落とす。

## Decision
真の重複判定は PDF バイト列の SHA-256 で行う。（公表時刻, コード, 表題）は一覧の差分検出（既知行のスキップ）にのみ使い、同一キーでも PDF のハッシュが異なれば別 event として登録する。

## Alternatives
- 表題＋時刻：別契約を落とす。却下
- 本文テキストのハッシュ：テキスト化の揺れで一致しない。PDF そのものを使う

## Consequences
- `events.pdf_sha256` に UNIQUE 制約。PDF取得失敗時は NULL（SQLiteでは NULL 同士は衝突しない）
- 一覧の差分検出で同一キーが再登場した場合も PDF を取得してハッシュを見る必要がある（アクセス回数は増えない：同一キーは通常1回しか出ない）
