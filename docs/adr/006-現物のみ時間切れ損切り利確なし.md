# 006: 現物のみ・20営業日時間切れ・△8%損切り・利確なし

- Status: Accepted
- Date: 2026-09-19
- Related: 要件8章、1章「戦略の確定事項」

## Context
個人のデイトレードで安定して勝つのは1%未満との記録があり、裁量と速度に依存する戦略は採らない。PEAD は時間で消える効果なので、出口は時間で決めるのが素直。損失の最大値を限定し、裁量の余地を消す必要がある。

## Decision
- 現物のみ。信用・空売りなし
- 出口は「20営業日目の引けで無条件売り」を主とする
- 損切りは建値から △8% で成行。実弾では発注時に逆指値を証券会社側に置く
- 保有中に下方修正・不祥事・監理指定が出たら翌朝売る（前提の崩壊）
- 利確はしない。ナンピン・買い増し・地合いでの見送りもしない
- 1銘柄は資金の5%、同時保有は最大10銘柄、1日の新規は最大3銘柄

## Alternatives
- 利確ルール：利益は右裾に集中する。途中で切ると期待値を削る
- トレーリングストップ：裁量の余地とパラメータの後出しを生む。初版では採らない
- 初日の失速で翌朝売り（銚子丸型）：600件で有効性を見てから。初版は記録のみ

## Consequences
- 出口ルールは `config/entry_rules.v1.yaml` の `exit` に版管理
- 模擬執行（paper）と実弾（manual）は同じ `rules.py` を使う
