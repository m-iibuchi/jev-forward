# 002: 主語固定文を全問いに入れ、評価軸は入れない

- Status: Accepted
- Date: 2026-09-19
- Related: 要件6章、検証ログ #12a〜12g, 27a/27b, 28/28b, 32a/32b、`config/questions.v2.json` の `_subject_prefix`

## Context
TOBや資本提携の開示で、Jevが買い手側の開示に対して対象会社の株主にとっての好材料を発行者に適用する誤判定（フェローテック 12a: up 85%）があった。stateの先頭に平文で注記しても直らず（12c）、問いのinstructionsに主語を入れると直った（27b: neutral 48→97%、12g: up 85→neutral 84%）。一方、主語に加えて「割高さ」「対象者の収益性」などの評価軸を入れると方向が反転し（12d/12e）、誘導になった。

## Decision
全問いの instructions 冒頭に、中立な主語固定文を入れる：
「判定対象は、この開示の発行者である{company}（証券コード{code}）自身の株価。開示に登場する他社（取引相手、公開買付けの対象会社、親会社・子会社など）の株価ではない。」
評価軸・判断の方向を含意する語句は入れない。文言はテンプレート固定で、判定時に `{company}` `{code}` のみ置換する。

## Alternatives
- stateに注記：効かない（12c）
- 評価軸入りの主語文：誘導になる（12d/12e）
- 買い手側の開示だけに入れる：判定前に役割を確定できない。単一当事者では無害（28 vs 28b）なので全件に入れる

## Consequences
- 問いの文言変更は版を上げる（CLAUDE.md ルール2・3）
- 主語の社名が本文にないと neutral に倒れる（12f）。コード・社名の紐付けミスは安全側に出るが、紐付け精度のテストが必要
