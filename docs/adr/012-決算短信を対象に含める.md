# 012: 決算短信もエントリー対象に含める

- Status: Accepted
- Date: 2026-09-20
- Related: 要件3章「対象開示」、6章 問い `category` `surprise`、ADR 007、基本設計3.2「主開示の選定」

## Context
要件v2のエントリー例は「業績予想の上方修正、増配、大型受注、資本業務提携」で、決算短信そのものは挙がっていなかった。また束ねの主開示優先順で決算短信は「資本政策」より下位。一方、PEAD研究の本家は決算短信のサプライズであり、SUEベースライン（ADR 007）も短信を前提にしている。短信を外すと、Jevが「数値以上の情報を足しているか」を最も測りたい場面で測れない。

## Decision
- エントリー条件は種類で絞らず、**direction up ≥ 80% かつ confidence ≥ 60%（および銘柄・規模・流動性・織り込み度の条件）を満たすもの全て**を対象とする。決算短信も含む
- 採点では `category` を使い、`earnings` の中で「決算短信」と「業績予想の修正」を表題で分けて集計する（探索）。主検証は分けない
- 束ねの主開示優先順は据え置く（業績予想の修正 > 不祥事 > 資本政策 > 決算短信 > 訂正・事務）。短信と同時に業績予想修正が出る場合は修正の方が新情報を含むことが多い

## Alternatives
- 初版は業績予想修正等に限定：解釈は単純だが、SUEベースラインとの比較対象が細り、短信のサプライズという本命を検証しない
- 前回予想がstateに入るまで短信を外す：F2-3 の実装後に版を上げて件数リセットになる。決算集中期を捕捉する時期と重なるので避ける

## Consequences
- 短信は本文が長い（数万字）。切り詰めルール（要件F2-4）の対象になることが多い。短信の要約表（サマリー1ページ目）を先頭優先で残す
- surprise 問いは前回予想・前期実績が state にないと機能しにくい。F2-3 の優先度を「高」から「必須（段階2開始まで）」に上げる
- 中間決算集中期（10月下旬〜11月中旬）に短信の件数が急増する。負荷要件（要件7章）の根拠になる
