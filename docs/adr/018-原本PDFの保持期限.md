# 018: 原本PDFはNAS移送後30日でVPSから削除可

- Status: Accepted
- Date: 2026-09-20
- Related: 要件7章「バックアップ」、基本設計6章、ADR 001

## Context
TDnet は決算集中日に366件、平時でも100件超の開示がある。PDF は数百KB〜数MB。VPS（1vCPU・1GB、ディスクは数十GB）に原本を無期限に置くと1年で数十GBになり、ディスク枯渇で fetcher が止まる。凍結ログ（SQLite）には本文テキストと SHA-256 が入っており、原本は再検証用。

## Decision
- 原本PDF（`data/raw/pdf/YYYY-MM-DD/`）は日次バックアップで NAS に rsync し、**NAS 側で転送完了を確認できた日付ディレクトリは30日経過後に VPS から削除してよい**
- 削除は `deploy/backup_to_nas.sh` の一部として行い、削除した日付とファイル数を `heartbeat.note` に記録する
- SQLite（凍結ログ）は削除しない。NAS には7日分のスナップショットをローテーション
- 保持日数は `config/settings.yaml` の `storage.raw_pdf_retention_days`

## Alternatives
- 原本を VPS に置かず NAS に直接保存：自宅回線依存
- 原本を保存しない：テキスト化の不具合を後から検証できない

## Consequences
- 「転送完了の確認」は rsync の終了コードと NAS 側のファイル数・サイズ照合で行う
- VPS のディスク使用率を heartbeat で監視し、80%超で通知
