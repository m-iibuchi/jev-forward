# 02: 設定（`src/jevfwd/settings.py`、`src/jevfwd/judge/questions.py`、`config/`）

- 対象：`settings.py`（`Settings` `EntryRules` `Filters` `Calendar` `Secrets` とローダー）、`judge/questions.py`（問い版の解釈と主語埋め込み）、`config/settings.yaml` `config/entry_rules.v1.yaml` `config/filters.v1.yaml` `config/trading_calendar.v1.yaml`、`docs/contracts/settings.schema.json`
- マイルストーン：M1
- 関連：CLAUDE.md ルール2・3・5、要件 F3-6・7章「保守」、基本設計 5章、ADR 002・003・016・019・020・023・025、task 011・014・015
- 版：2026-09-20 初版（同日 M3 追補：`primary_priority` 等、`StateCfg`、`Calendar`。同日追補2：`bundle.poll_sec`（task 017）、4.7 に SHA-256 を記録・T02-35 の例を訂正（task 019・022））

## 1. 責務

- YAML / JSON の設定ファイルを読み、型を検証し、不変オブジェクトとして他モジュールに渡す。設定値の意味は解釈しない（周期の実行、閾値の適用は各モジュール）
- 版付きファイル（`questions.vN.json` `entry_rules.vN.yaml` `filters.vN.yaml` `trading_calendar.vN.yaml`）は**作成後に変更しない**。変更検知は SHA-256 定数のテスト（ADR 020）
- 秘密（API キー等）は環境変数からだけ読み、ログや `repr` に出さない
- `judge/questions.py` は問い版 JSON を TypeSafe の questions 形式（v1 と同じ形）に変換する。文言は一切変えない。`{subject}` `{company}` `{code}` の置換だけを行う（ADR 002）

しないこと：`.env` の読み込み（Docker compose か `set -a; source .env` に任せる）、設定値の上書き・マージ・環境別プロファイル、TypeSafe API の HTTP 要求本体の組み立て（M4 `judge/client.py`。task 002 待ち）。

## 2. 依存

- `pyyaml`（`yaml.safe_load` のみ）、`pydantic>=2`
- `jevfwd.common`（`hashing` `errors`）
- `judge/questions.py` は `settings.py` を import しない（純関数。版の文字列と JSON 文字列だけを受け取る）

### 3.2 `judge/questions.py`

```python
SUBJECT_PLACEHOLDER = "{subject}"
META_PREFIX = "_"
QTYPES = ("noul", "score", "choice")

@dataclass(frozen=True)
class Question:
    id: str
    type: str                      # noul / score / choice
    instructions: str
    criteria: dict[str, str] | list[str]   # choice/noul は dict、score は list

@dataclass(frozen=True)
class QuestionSet:
    version: str
    subject_prefix: str | None     # _subject_prefix（v1 は None）
    meta: dict[str, object]        # _ で始まるキー全部（_version, _frozen_at, _notes, _subject_prefix）
    questions: tuple[Question, ...]   # ファイル内の出現順

def parse(text: str, version: str) -> QuestionSet:
    """JSON 文字列を解釈する。DB の question_versions.json からも、ファイルからも同じ関数。
    - _ で始まるキーは meta。_version があれば version と一致必須（不一致は ConfigError）
    - 残りは問い。各問いは type / instructions / criteria を持ち、type は QTYPES、
      criteria は score なら list[str]（5要素）、noul なら keys {true,false}、choice なら dict[str,str]。違反は ConfigError
    - {subject} を含む問いがあるのに _subject_prefix が無ければ ConfigError"""

def load_file(path: Path) -> QuestionSet:
    """版はファイル名 questions.vN.json から。text = path.read_text(encoding="utf-8") を parse に渡す"""

def render(qs: QuestionSet, company: str, code: str) -> dict[str, dict]:
    """TypeSafe の questions 形式に変換する（v1 の JSON と同じ形）。
    - subject = subject_prefix.replace("{company}", company).replace("{code}", code)（subject_prefix が None なら ""）
    - instructions = instructions.replace("{subject}", subject)
    - 出力は {question_id: {"type": ..., "instructions": ..., "criteria": ...}} のみ。meta は含めない
    - criteria は変更しない。出力に "{" が残っていたら ConfigError（未知のプレースホルダの検知）
    - code は表示用4文字（common.codes.display_code の結果）を渡す。5文字のまま渡すのは呼び出し側の誤り（ValueError）"""

def render_from_db(conn, version: str, company: str, code: str) -> dict[str, dict]:
    """queries.get_question_version(conn, version) の json を parse → render。無ければ JudgeError（ADR 020）。M4 の judge が使う"""
```

low_priority_titles:

### 4.5 `docs/contracts/settings.schema.json`

`Settings.model_json_schema()` の出力を `json.dumps(indent=2, ensure_ascii=False, sort_keys=True)`（末尾に改行1つ）で保存したもの。手で書かない。`Settings` を変えたら再生成して commit する（テスト T02-23 が不一致を検知）。基本設計5章の `settings.schema.yaml` はこのファイルに読み替える（★）。

### 4.6 問い版 JSON の形

- ファイル名 `config/questions.vN.json`。UTF-8、BOM なし。ファイルは作成後不変（SHA-256：v1 `14a8baac5898235be756d1c4265fc39541adf13108d9bbc04a445cabf65bd2e7`、v2 `3f7b661012e0ab94c22f3012bb76a72cc2a03cd086e26b5208fc5b6455f6bcb0`。ADR 020）
- トップレベルは object。`_` で始まるキーはメタ（`_version` `_frozen_at` `_notes` `_subject_prefix`）。それ以外は問い ID → `{type, instructions, criteria}`
- `_subject_prefix` は `{company}` `{code}` を含む文字列。各問いの `instructions` は `{subject}` を含んでよい（v2 は7問すべて先頭に含む）。`{subject}` 以外の `{…}` は使わない
- `render` の出力（TypeSafe の questions 形式）は v1 のファイルと同じ形：`{"direction": {"type": "choice", "instructions": "...", "criteria": {...}}, ...}`。HTTP 要求全体（`model` `state` を含む）の形は task 002 の採取後に `07-判定.md` で決める

## 5. エラー時の振る舞い

| 事象 | 振る舞い |
|---|---|
| 設定ファイルが無い | `ConfigError("設定ファイルがありません: <path>")` |
| YAML 構文エラー | `ConfigError`（`yaml.YAMLError` を包む。行番号を含める） |
| 未知キー・型不一致・欠落 | `ConfigError`。pydantic の `ValidationError` を包み、メッセージにキーのパス（`market.session_open`）を含める |
| `"HH:MM"` を未クォートで書いた | pydantic に int が渡り `StrictStr` で失敗 → `ConfigError`。メッセージに「クォートが必要」を添える |
| `version` とファイル名の版が不一致 | `ConfigError` |
| 正規表現がコンパイルできない | `ConfigError`（どのキーの何番目か） |
| 秘密が未設定で `require` | `ConfigError("環境変数 TYPESAFE_API_KEY が未設定")`。値は絶対に含めない |
| `parse`：`type` 不明、`criteria` の形が違う、`_version` 不一致、`{subject}` があるのに `_subject_prefix` 無し | `ConfigError` |
| `render`：出力に `{` が残る | `ConfigError`（未知プレースホルダ） |
| `render`：`code` が4文字でない | `ValueError` |
| `render_from_db`：版が未凍結 | `JudgeError("問い版 v2 は未凍結。jevfwd freeze-questions --version v2")`（ADR 020） |
| `Calendar`：収録年の外の日付 | `ConfigError("trading_calendar v1 は 2026-2027 のみ収録。2028-01-04 は判定できない")`。黙って平日扱いにしない |
| `Calendar`：`holidays` の日付が `MM-DD` でない | `ConfigError`（どの年の何番目か） |

例外はすべて `common.errors` の型。pydantic / yaml の例外をそのまま外に出さない。

## 7. 擬似コード

```python
# settings.py
def _load_yaml(path: Path) -> dict:
    if not path.exists():
        raise ConfigError(f"設定ファイルがありません: {path}")
    try:
        data = yaml.safe_load(path.read_text(encoding="utf-8"))
    except yaml.YAMLError as e:
        raise ConfigError(f"{path}: YAML が読めません: {e}") from e
    if not isinstance(data, dict):
        raise ConfigError(f"{path}: トップレベルは mapping")
    return data

def _validate(model, data, path):
    try:
        return model.model_validate(data)
    except ValidationError as e:
        locs = "; ".join(".".join(str(x) for x in err["loc"]) + ": " + err["msg"] for err in e.errors())
        hint = "（\"HH:MM\" はクォートが必要）" if any(err["type"] == "string_type" for err in e.errors()) else ""
        raise ConfigError(f"{path}: {locs}{hint}") from e

def load_settings(path):      return _validate(Settings, _load_yaml(path), path)
def load_entry_rules(path):
    rules = _validate(EntryRules, _load_yaml(path), path)
    _check_version(rules.version, version_from_filename(path, "entry_rules"), path)
    return rules
def load_filters(path):
    f = _validate(Filters, _load_yaml(path), path)
    _check_version(f.version, version_from_filename(path, "filters"), path)
    for key in ("exclude_code_patterns", "exclude_titles", "low_priority_titles", "tob_titles", "sequence_patterns"):
        for i, pat in enumerate(getattr(f, key)):
            try: re.compile(pat)
            except re.error as e: raise ConfigError(f"{path}: {key}[{i}] の正規表現が不正: {e}") from e
    return f

# questions.py
def parse(text, version):
    data = json.loads(text)                                  # JSONDecodeError → ConfigError
    meta = {k: v for k, v in data.items() if k.startswith(META_PREFIX)}
    if "_version" in meta and meta["_version"] != version:
        raise ConfigError(f"_version={meta['_version']} がファイル名の版 {version} と一致しない")
    subject_prefix = meta.get("_subject_prefix")
    qs = []
    for qid, q in data.items():
        if qid.startswith(META_PREFIX): continue
        _check_question_shape(qid, q)                        # type / instructions / criteria
        if SUBJECT_PLACEHOLDER in q["instructions"] and subject_prefix is None:
            raise ConfigError(f"{qid}: {{subject}} があるのに _subject_prefix が無い")
        qs.append(Question(qid, q["type"], q["instructions"], q["criteria"]))
    return QuestionSet(version, subject_prefix, meta, tuple(qs))

def render(qs, company, code):
    if len(code) != 4: raise ValueError("code は表示用4文字（common.codes.display_code）")
    subject = (qs.subject_prefix or "").replace("{company}", company).replace("{code}", code)
    out = {}
    for q in qs.questions:
        ins = q.instructions.replace(SUBJECT_PLACEHOLDER, subject)
        if "{" in ins: raise ConfigError(f"{q.id}: 未知のプレースホルダが残っている")
        out[q.id] = {"type": q.type, "instructions": ins, "criteria": q.criteria}
    return out
```
