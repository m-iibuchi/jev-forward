## 主検証（1つだけ）

- **母集団**：`bundle_role='normal'`、`session IN ('after_close','pre_open')`（公表が 15:00:00 JST 以降〜翌営業日 8:59:59 JST。場中開示は含めない。ADR 011）、`purpose='full'`、`model='jev-latest'`、`delayed=0`、エラーなし
- **エントリー条件**：direction up ≥ 0.80、confidence ≥ 0.60、時価総額 < 1,000億円、直近20営業日の平均売買代金 ≥ 1億円、開示前20営業日の対TOPIX超過リターン < +10%。開示の種類では絞らない（決算短信を含む。ADR 012）
- **1件の定義**：上記を満たす判定1つ × 1銘柄。同一銘柄で評価期間が重なる件は、エントリー日昇順で直前採用件の終点日以前のものを `overlap_excluded=1` として数えない
- **起点**：翌営業日の始値（寄らなければ約定なし `filled=0`。寄らずの判定は日足の代理指標、task 010）
- **終点**：20営業日後の終値
- **指標**：対TOPIX超過リターン、コスト（往復手数料 0.1% ＋ スリッページ 0.2%）控除後。確率 100% / 0% は 99.5% / 0.5% に丸める
- **件数・期間**：600件、最低4週間、上昇・下落局面を含む。決算集中期と平時を分けて集計もする（結論は全体で）

## ベースライン（同期間・同条件で並走）

1. **ランダム**：各エントリー日に、その日の引け後開示銘柄のうち主検証と同じ除外・規模・流動性・織り込み度条件を満たすものから、主検証と同数を無作為抽出。乱数 seed = **20260915**（固定。`outcomes.random_seed` に記録）
2. **ホールド**：TOPIX（取得方法は task 003 で確定し、ここに追記）
3. **SUEのみ**：Jev を使わず、営業利益の修正率の上位から主検証と同数・同条件で選ぶ。修正率の定義は task 005 で確定し、ここに追記する（暫定：業績予想修正は (今回予想 − 前回予想) / |前回予想|、決算短信は (実績 − 前回予想) / |前回予想|、前回予想が 0 または取得不能の件は母集団から除外し件数を記録）

## 判定基準（ADR 013）

- **帰無仮説**：主検証の平均超過リターン ≤ 各ベースラインの平均超過リターン
- **検定**：日別ブロック・ブートストラップ
  1. 主検証の各件と、対応するベースラインの各件について、コスト控除後の対TOPIX超過リターンを求める
  2. エントリー日を1ブロックとし、ブロックを復元抽出（ブロック数＝元の営業日数）して「主検証の平均 − ベースラインの平均」を計算。これを **10,000回** 繰り返す。乱数 seed = **20260915**
  3. 差の分布の **両側95%区間（2.5% / 97.5% 分位）の下限が 0 を上回る** とき、そのベースラインに有意に勝つ
- **通過**：3ベースラインすべてに対して上記が成立
- **感度分析**（結論には使わない）：ブロックを ISO 週に広げて同手順。結論が異なればレポートに併記
- **単純な t 検定は使わない**（同日・重なり期間の依存で甘くなる）
